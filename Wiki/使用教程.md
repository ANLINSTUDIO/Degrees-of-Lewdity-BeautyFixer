## 一、打开编辑器

1. 在游戏里穿好想修的服装（编辑器要靠游戏画面提供底图和图层列表）。
2. 点侧栏的 **美化修正** 按钮，打开选图面板。
3. 在列表里点任意一张图，进入编辑器。

> 打开列表时如果提示「暂无可修正的图像」，说明当前身上没有可修的部位，先去换上衣服。

---

## 二、选图面板

顶栏从左到右：

| 控件 | 作用 |
| --- | --- |
| 搜索路径 | 输入关键词过滤（如 `dress`、`hair`） |
| 部位 / 状态 / 排序 | 按槽位筛选、只看「已修正」或「未修正」、按路径或修正时间排序 |
| 导出 | 导出**全部**修正为修正码 |
| 导入 | 展开码区，准备粘贴修正码 |
| 关闭 | 关掉面板 |

列表按「同一套衣服」自动分组（槽位 + 名称相同即为一组），组头上有：

- **导出** —— 只导出这一套的修正码
- **还原** —— 一键清除这一套的全部修正
- **编辑服装组合** —— 把这套的所有部件一起放进编辑器（见第十一节）

每张图右侧：

- **已修正** 标记：这张图被改过
- **还原** 按钮：只还原这一张

## 三、编辑器界面总览

界面分四块：

### 1. 顶栏（最上方）

| 按钮 | 作用 |
| --- | --- |
| ‹ 返回 | 回到选图面板（**不保存**未保存的改动） |
| 撤销 / 重做 | 回退或重做一步操作（最多 20 步） |
| 还原 | 把当前正在编辑的对象恢复成原版 |
| 保存并生效 | 保存并立刻应用到游戏 |
| 关闭 | 直接关掉整个面板 |

### 2. 画布区（中间）

- 棋盘格是透明背景。
- 左上角有 **⋯ 更多工具** 按钮，点开是折叠菜单。
- 更多菜单下方是 **控制器区**：复像面板、图层缩放控制器、分割提示条，会按当前工具自动出现或隐藏。

### 3. 工具面板（右侧）

**工具栏（一排图标）：**

| 图标 | 工具 | 用途 |
| --- | --- | --- |
| 框选 | 框选 | 拖框选中一块原图区域，松手后可复制成新图层或删除 |
| 移动 | 移动 | 拖动选中图层 |
| 画笔 | 画笔 | 在编辑图层上画 |
| 橡皮 | 橡皮 | 擦掉原图/图层的内容 |
| 缩放 | 图层缩放 | 打开缩放控制器，并可在画布上拖四角手柄缩放 |

**颜色行：**

- **颜色** —— 画笔颜色
- **取色**（吸管图标）—— 全图层取最前可见像素，盖出可移动的色块；编辑器内按 **Alt** 键也能临时取色。
- **粗细** —— 画笔粗细（1~32）
- **浓度** —— 画笔不透明度（10%~100%）

**X / Y 行：** 用 − ＋ 按钮每次把当前图层挪一个像素，用于精细对位。

**视图行：**

| 按钮 | 作用 |
| --- | --- |
| － / ＋ | 缩小 / 放大画布视图 |
| 适应窗口 | 把整张图缩放到刚好放进窗口 |
| 刷新人物背景 | 重新抓取游戏里的角色底图 |
| 显示服装 / 隐藏服装 | 默认把身上其它服装藏起来，方便对齐；点一下可切换 |

**明度三条滑杆：**

| 滑杆 | 作用 |
| --- | --- |
| 人物背景 | 底图（角色身体）的透明度 |
| 服装前景 | 正在编辑的这件服装的整体透明度 |
| 棋盘明度 | 棋盘格的明暗，只影响观看，不进导出数据 |

> 这三个滑杆以及所有滑杆旁的**数值都可以直接点**，会弹出输入框精确输入；
> 输入超出范围的值会被拒绝并提示允许范围。

### 4. 图层条（画布底部）

从左到右：**＋ 新建** → 上层图层 → …… → 最底层 → **原图层**（固定在最右，不可移动、不可删除）。

每一片图层上：

- **▣ / ▢** —— 显示 / 隐藏该层
- **图层名** —— 双击可重命名
- **✕** —— 删除该层（原图层没有此按钮）
- 空图层显示斜向灰色条纹
- 「锁定」标记表示该层为原图层或参考层

## 四、基础操作：把部件对齐

最常见的用法：衣服位置偏了，把它挪正。

1. 选 **移动** 工具。
2. 在画布上拖动，或用 X / Y 的 − ＋ 按钮一像素一像素微调。
3. 想看清对齐情况，点更多菜单里的 **显示网格**。
4. 满意后点 **保存并生效**。

**移动的判定规则**（不同图层类型不同）：

- **原图层 / 复制块**：整层跟着鼠标走。
- **笔迹层**：拖到哪算哪。
- **组合模式**：整组部件一起动。

## 五、画笔与橡皮

### 画笔

1. 选 **画笔** 工具。
2. 调好颜色、粗细、浓度。
3. 在画布上拖动即可绘制。

- 如果当前选中的是**原图层或复制块**（这两类不支持直接画），会自动帮你切到（必要时新建）一个笔迹层，并弹出提示。
- 撤销 / 重做对每一笔都有效。

### 橡皮

1. 选 **橡皮** 工具。
2. 在当前图层上涂抹，涂过的地方变透明。

- 橡皮改的是「擦除遮罩」，原图像素不会被真的破坏。
- 用橡皮改过之后保存，擦除效果会一并保存；如果没用橡皮，则原样沿用上次的擦除数据。
- 擦除区域会跟着图层一起移动 / 缩放，不会错位。

## 六、缩放图层

### 方式一：控制器（推荐）

1. 点工具栏的 **缩放** 按钮。
2. 图层缩放的控制器出现在画布左上角：
   - **滑杆** —— 自由缩放 25%~400%
   - **<< / >>** —— 跳到对齐档（25% / 50% / 100% / 200% / 400%），整倍最锐利
   - **✓** —— 确认，位置取整到像素网格
   - **✕** —— 取消，恢复到进入调节前的状态
3. 完成后点 ✓ 或 ✕ 退出。

### 方式二：拖四角手柄

进入缩放状态后，选中图层周围会出现金色虚线框和四个角手柄：

- 鼠标移到角上，光标变成对角拉伸箭头。
- 拖动即缩放，**对角固定不动**。

### 多选缩放

不确定要调哪层、或者想让好几个部件一起放大缩小时：

1. 进入缩放状态（工具栏 **缩放** 按钮）。
2. 点图层条里的图层片 —— 点一下**加入**缩放列表，再点一下**移出**。
3. 选满两个以上时，控制器下方会出现 **「多选：N图层」** 字样。
4. 此时滑杆、<< >>、✓、✕ **同时作用于所有选中层**：
   - 滑杆按同一比例缩放整组，各层相对大小不串位。
   - 拖四角手柄时，整组绕**同一个固定点**缩放，相对位置关系整体保持。
5. ✕ 取消会把整组一起还原；✓ 确认整组一起定格。

### ⚠ 缩放的后遗症：像素偏移

图层放大后，原本 1 格的内容会摊到好几个像素上（比如放大 3 倍，原来 1 格摊成 3×3）。
即使缩放比例是整数倍，**非整像素的落点也会让边缘发虚、网格对不齐、橡皮一擦就是一大片**。
这是缩放的天性，修法见下一节。

## 七、像素压制

**技术名词：像素压制（Pixel Rebake）** —— 把缩放过的图层框选复制成块，让摊开的像素重新落回
「1 格 = 1 像素」的基准网格。

### 为什么需要它

- 图层放大 3 倍后，橡皮擦一下其实是在擦「原本 1 格、现在摊开成 9 格」的那片区域，边缘糊、擦不精细。
- 把它框选**复制成块**后，块里的内容被重新按基准网格采样定格：**1 格就是 1 像素**。
- 之后再缩放 / 移动这个块，橡皮操作的就是真实的单像素，**便于精细处理**。

### 怎么做

1. 对缩放好的图层，选 **框选** 工具，把它整个框住。
2. 松手后选 **复制**，生成一个「复制块」图层。
3. 删掉（或隐藏）原来那层，只留块 —— 此时像素已归位，网格对齐、橡皮也精细了。

> 日常口诀：**先缩放，后压制，再细修。**

## 八、图层条

| 操作 | 怎么做 |
| --- | --- |
| 新建图层 | 点最左的 **＋** |
| 选中图层 | 点图层片 |
| 显示 / 隐藏 | 点 **▣ / ▢** |
| 重命名 | 双击图层名 |
| 删除 | 点图层片上的 **✕**（可撤销） |
| 调整顺序 | **鼠标**：按住图层片左右拖动；**触屏**：用选中层两侧出现的 **‹ / ›** 按钮 |

说明：

- 图层永远不会跑到原图层后面，原图层始终在最底、最右。
- 拖动排序时是松手才一次落位，跟手不抽搐。
- 鼠标滚轮停在图层条上，滚的是图层条本身，不会缩放画布。

## 九、更多工具

点画布左上角的 **⋯** 展开：

| 菜单项 | 作用 |
| --- | --- |
| **启用复像 / 关闭复像** | 打开对称轴面板 |
| **显示网格 / 隐藏网格** | 网格对齐参考线 |
| **复制图层** | 复制当前选中的图层，副本出现在原层上方 |
| **合并图层** | 把当前图层与它下一层（右侧相邻层）合成为一个块 |
| **分割图层** | 在图层上划一条直线，行进方向右侧分离成新图层 |
| **导出人物背景** | 把当前的人物快照（先点过「刷新人物背景」）存成 PNG 文件 |

### 复像（镜像）

打开复像后，画布左上角出现控制器：

- **关闭复像** —— 退出
- **镜像** —— 以线为轴逐像素左右翻折
- **同像** —— 线两侧互相同步平移复制（朝向不变，左边界有源线标记）
- **线** —— 调整对称轴位置

常用于对称的服装部件：改好一侧，另一侧自动跟上。

### 网格

显示网格后：

- 网格线始终落在像素边界上，缩放时自动调整格距，不会出现摩尔纹。
- 配合整倍缩放档对位最准。

### 复制图层

选中要复制的图层 → 更多菜单 → **复制图层**。副本会出现在原层上方，可单独移动、擦除、再次复制。

### 合并图层

选中一个图层 → **合并图层**，它会和右侧相邻的下一层合成一个块。

- 合并后仍是一个可移动、可擦除的整体。
- 想撤销就点顶栏的撤销。

### 分割图层

1. 更多菜单里点 **分割图层**。
2. 画布左上角出现提示条：**「在图层上划一条直线，行进方向右侧分离为新图层」**，旁边有 **取消切割** 按钮。
3. 在图上划一条线 —— 预览线会显示成贯穿整张图的直线（和实际切割线一致）。
4. 松手即分割，**分割完成后自动退出**这个模式。

细节：

- **笔迹层**直接按线分。
- **复制块**按遮罩分。
- **原图层**会被拆成两张互补的原图配方。
- **失败不退出**：如果线画得太短、或划线右侧没有内容，会留在原地方便重划。
- 按住 **Shift** 拖动可吸附 0°/45°/90°/135° 并落在整像素上，切割边缘更干净。
- 三种分割都支持撤销 / 重做。

## 十、框选与复制块

1. 选 **框选** 工具。
2. 在画布上拖出一个框，松手。
3. 弹出选择浮层，可选 **复制** 或 **删除**。

**复制**会生成一个「复制块」图层：

- 作为正常图层出现在图层条里并自动选中。
- 可以移动、缩放、擦除、再次框选。
- 支持撤销 / 重做。
- 复制块内如果含有笔迹，笔迹会被一起冻结带走。

## 十一、服装组合：多部件一起动

一套衣服往往由好几个部件文件组成（例如上衣 + 袖子 + 领子）。整组一起移动的用法：

1. 在选图面板的组头上点 **编辑服装组合**。
2. 编辑器里会载入这套衣服的全部部件，其它部件作为**参考层**（带「锁定」标记）。
3. 顶部工具栏会出现 **组合** 按钮，默认已打开（高亮）。
4. 此时用移动工具拖动，**所有部件一起动**，整组相对位置不变。
5. 再点 **组合** 按钮可关掉，改成只动当前选中的部件。

> 想单独处理某个参考层，先用 **框选** 把它复制成块，再对块操作。

## 十二、导出人物背景

编辑器里 **刷新人物背景** 抓到的人物快照，可以整张存成 PNG 文件：

1. 先点视图行的 **刷新人物背景**，抓到当前人物。
2. 点更多菜单里的 **导出人物背景**。
3. 弹出保存框，存成 `人物背景.png`。

- 双帧图会导出两帧（内容相同）。
- 「隐藏服装」开着时刷新的背景，导出的就是无衣版本。

## 十三、保存与还原

### 保存

改完点顶栏 **保存并生效**。保存后：

- 立刻在游戏画面里生效。
- 存进浏览器数据库，重进游戏、刷新页面都还在。

### 还原

- **单张图**：编辑器顶栏 **还原**，或在选图面板里点该图的 **还原**。
- **整套衣服**：选图面板组头点 **还原**，会清掉这套的全部修正并复位图层。
- 编辑器里做错了，随时用 **撤销**（最多 20 步）。

## 十四、导出与分享

在选图面板点 **导入**（或点 **导出**）展开码区：

| 按钮 | 作用 |
| --- | --- |
| **复制修正码** | 把修正码复制到剪贴板 |
| **存为文件** | 把修正码保存成 `.txt` 文件下载到本地 |
| **应用导入** | 把上面文本框里的修正码导入并生效 |
| **从文件导入** | 选一个 `.txt` 修正码文件，读入并生效 |

### 发的人

- 码短：**复制修正码**，直接贴到聊天里发出去。
- 码长（社交平台有字数上限）：点 **存为文件**，把 `.txt` 丢进群文件 / 网盘 / 分享帖。

### 收的人

- 收到的是文字：粘贴到文本框 → **应用导入**。
- 收到的是文件：下载后点 **从文件导入** → 选中该文件 → 自动生效。

### 只发一套

在选图面板那一套衣服的组头上点 **导出**，只导出这一套（含组位移）。

## 十六、常见问题

**Q：列表里找不到想改的衣服？**
A：先在游戏里把它穿上；列表只显示当前角色身上实际加载的图像。

**Q：画笔点下去没反应，只弹了个提示？**
A：你选中的是原图层或复制块，这两类不支持直接绘制。系统已自动帮你切到笔迹层，继续画即可。

**Q：放大后橡皮一擦一大片、边缘糊？**
A：像素被摊开了。用 **像素压制**：框选 → 复制成块，像素即归位（见第七节）。

**Q：导入修正码提示「不是有效的修正码」？**
A：码被截断或混入了其它字符。让别人重新导出一次再发；文件方式传输不容易出问题。

**Q：导入后复制块 / 擦除区域不对？**
A：重新导出一次修正码再导入。旧版本导出的码不保证能被当前版本读取。

**Q：想改的东西被前面的衣服挡住了？**
A：点右侧的 **显示服装 / 隐藏服装** 切换，或调低「服装前景」滑杆。

**Q：导出图层时提示读不到原图？**
A：游戏用 file:// 打开时浏览器禁止直读本地图片，会新开一页显示原图，右键「另存为」即可；游戏页面还在原来的标签页里。

**Q：整个面板的弹窗挡住游戏了？**
A：点顶栏 **关闭** 或 **‹ 返回** 退出编辑器。

## 十七、实战参考步骤

当你需要为原版没有美化的上半身服装去适配类似Goose**等带有人物特写的美化**时，有一套可供参考的完整流程。

### 正常处理全身模型服装

1. 点击目标服装组的「编辑服装组合」
    ![image-20261003224843003](assets/image-20261003224843003.png)
    
2. 选择「缩放工具」
    ![image-20261003224901678](assets/image-20261003224901678.png)
    
3. 保持「原图」亮起，依次选中图层区的其他&nbsp;「配件」，直至所有图层全部亮起
    ![image-20261003224927405](assets/image-20261003224927405.png)
    
4. 使用「移动工具」和「控制器」的滑条、数值、对齐按钮以及「画布」上的四角控制点，去调整服装的位置和大小，直到适配人物模型
    ![image-20261003230526244](assets/image-20261003230526244.png)
    
5. 注意，一般无需调整大小，但若调整了大小，则看此步。如果调整大小，则会出现右服装向左偏移的情况
    ![image-20261004002244622](assets/image-20261004002244622.png)
    要解决，请先完成「缩放工具」，然后在「更多工具」中选择「分割图层」
    ![image-20261004002554614](assets/image-20261004002554614.png)
    在控制器中选择「全图切割」，并在两件服装中间任意位置画一条垂直线（按住Shift可以锁定角度)
    
    ![image-20261004002750809](assets/image-20261004002750809.png)
    完成切割后，两帧的服装则被分离开来。之后先关闭「组合」模式，再使用「缩放工具」选中“分割右”的所有图层，并拖动它们到正确位置
    
    ![image-20261004004159068](assets/image-20261004004159068.png)
6. 最后点击「保存并生效」，这就是最基本的服装处理方式
    ![image-20261004004409970](assets/image-20261004004409970.png)
    ![image-20261004004629957](assets/image-20261004004629957.png)

### 细节处理

1. 粗略处理发现人物的脸部等位置可能被衣服遮挡，或者有其他需要调整的地方，此时可以使用「画笔工具」、「橡皮工具」以及「取色工具」进行细微调整。
    ![image-20261004154923604](assets/image-20261004154923604.png)

2. 因为图片有两帧宽，我们为了方便，可以在「更多工具」中启用「复像工具」，「复像工具」的「同像模式」就是专门处理这个问题的，工具默认将**像线**定位在中间，一般无需修改，此时画笔、橡皮、取色均可以实现左右同步的效果。

    ![image-20261004155457577](assets/image-20261004155457577.png)

3. 因为服装偏深色，为了能够看清人物，我们拉高「人物背景」和「棋盘明度」。选择「橡皮工具」，选中原图图层，将遮挡人物的像素擦除即可。
    ![image-20261004155738353](assets/image-20261004155738353.png)

4. 发现有部分地方需要填补，我们选择「画笔工具」，并通过「色块选择器」的取色器获取需要的颜色，通过画笔**连续**绘制。**部分浏览器如手机端，可能无法使用取色器，那么推荐使用「取色工具」**
    ![image-20261004155903341](assets/image-20261004155903341.png)

5. 当需要修补的格数不多，则可以使用「取色工具」。点击「色块选择器」右侧的「取色工具」，使其高亮，并在视图中选择「粗细」像素的「源色块」。被标记为蓝色边框的色块就是用于**复制**的源色块了，有了源色块后，在视图中进行**点画**便可以复制出源色块的内容。再次点击「取色工具」以完成。

    - 注意，「取色工具」只能**点画**，不像「画笔工具」一样能够连续绘制。
    - 电脑端使用 alt 键可以快速启用「取色工具」。

    ![image-20261004160815765](assets/image-20261004160815765.png)

### 美化特写处理（仅上半身服装）

1. 使用「选择工具」，框选住服装上半部分，选择「复制」
    ![image-20261004162459545](assets/image-20261004162459545.png)
2. 复制的新图层为「冻块」，范围无法自动包裹收紧。将复制的新图层移动到特写处，对齐左边界。**通过手动收紧冻块图层，我们可以更方便的通过四角进行缩放。**选择「缩放工具」，拖动左「边控制器」直到完成包裹。然后拖动右下「点控制器」进行缩放，直到左右两端均与人物对齐。
    ![gif_20261004163209](assets/gif_20261004163209.gif)
3. 向上调节到适当位置。随后进行「像素压制」，将缩放彻底应用。
    ![gif_20261004163734](assets/gif_20261004163734.gif)
4. 按照Goose边框擦除超出像素，并且通过「画笔工具」、「橡皮工具」以及「取色工具」进行衣物微调。
    ![image-20261004165318463](assets/image-20261004165318463.png)
5. 为了适配Goose边框，我们需要将特写部分的图层**下边和右边各1像素**进行删除。选择「橡皮工具」，对其进行处理。
    ![image-20261004171047181](assets/image-20261004171047181.png)
6. 在「更多工具」中选择「复制图层」，将另一帧也打上同样的内容。完成后点击「保存并生效」
    ![gif_20261004171448](assets/gif_20261004171448.gif)
7. 关闭窗口，恭喜。你已经完成了最粗糙的教学。接下来如何精细处理，就看你自己的造化了！
    ![image-20261004171619005](assets/image-20261004171619005.png)
